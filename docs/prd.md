# 需求文档

## 1. 应用概述

### 1.1 应用名称
研选 · 自然语言智能选股与策略解释器

### 1.2 应用描述
面向 A 股投资研究场景的辅助工具。产品将用户的模糊选股意图转化为结构化、可修改、可执行的筛选条件，通过确定性筛选引擎产出有真实数据支撑的候选股票列表，并提供逐条件归因核对、What-if 敏感性分析、多指标对比观察、简化历史回测及策略监控能力。产品定位为研究辅助工具，不构成交易或投资建议。

## 2. 用户与使用场景

### 2.1 目标用户
个人投资者、证券投资顾问、行业研究员及量化策略初学者。

### 2.2 核心使用场景
- 意图快速转策略：通过自然语言描述选股想法，快速生成可执行的多因子选股条件组合。
- 归因核对与归因解释：查看个股入选或被剔除的具体因子数值与口径来源，定位筛选边界。
- 因子敏感性测试：调整因子阈值，即时观察边缘股票进出名单与数量变动。
- 策略检验与跟踪：基于历史数据回测策略表现，保存策略并开启每日监控跟踪。

### 3.2 核心功能说明

#### 3.2.1 顶部导航与状态栏
- 应用标识与数据状态：展示应用名称，根据当前底层数据提供者动态展示「演示数据快照」或「真实 API 接入」状态徽标；未配置 API Key 时固定显示演示数据快照提示。
- 合规声明：提供全局合规弹窗入口，说明研究辅助属性与免责声明。

#### 3.2.2 意图输入与解析区
- 输入与快捷填充：提供多行自然语言输入框，下方提供 4-6 个典型示例短语（如「经营改善、估值合理、走势相对稳定」），点击可直接填充至输入框。
- 解析与反馈：点击「解析意图」后，展示步骤式解析轨迹，说明识别到的关键词、映射生成的指标及其默认操作符与阈值。
- 歧义与冲突提示：当意图存在多种口径解释时，弹出可选口径确认框；当存在互斥硬冲突时阻断并提示修正；当存在张力组合（如高成长且高股息）时展示警示信息但允许继续执行。

#### 3.2.3 条件卡片配置区
- 条件卡片列表：将解析结果转化为独立卡片展示。每张卡片展示指标名称、比较操作符、当前阈值/区间、指标口径说明（含定义、统计时点、来源和单位），并提供启用/禁用开关、阈值直接编辑控件与删除按钮。
- 条件联动：卡片阈值修改、启停切换、增删操作完成后，即时触发筛选引擎重新计算。
- 添加条件面板：支持从指标库按类别（估值、成长、盈利质量、动量、波动、股息、市值、流动性）浏览并添加新条件，每个指标均附带通俗定义与适用口径说明。

#### 3.2.4 筛选结果展示区
- 统计与概览：展示当前筛选条件下的全市场股票通过率百分比，以及主要被排除原因 Top 汇总。
- 候选列表：以表格呈现通过筛选的股票，包含代码、名称、行业、现价、市值及触发筛选的各项关键指标数值；支持字段升降序排列与按行业筛选。
- 交互入口：列表支持单选进入明细抽屉，支持多选加入对比观察池。

#### 3.2.5 股票明细核对抽屉
- 逐条件核对：展开选中股票的完整检验清单，罗列全部生效条件。
- 三态判定标签：每个条件明确标记「通过」「不通过」或「数据缺失」。
- 追溯信息：逐项列出该股票的实际指标数值与条件阈值对比，展示该字段对应的数据时点与披露口径来源。

#### 3.2.6 What-if 敏感性分析面板
- 变量调节：允许用户从生效条件中选定单个指标，提供 ±10% 和 ±20% 快捷微调按钮与自定义滑块。
- 边际名单呈现：即时展示因阈值调整而新增纳入或被剔除的股票名单。
- 影响说明：输出文字摘要，明确阐释「阈值放宽会纳入 X 只、收紧会剔除 Y 只」的边际变动结论。

#### 3.2.7 对比观察池面板
- 多指标横向比对：以矩阵表格呈现已加入对比池的股票，横向平铺对比其估值、成长、质量、行情等全维度数据，并高亮极值项。

#### 3.2.8 简化历史回测面板
- 历史回放：基于所配置的条件规则，在历史调仓时点（每期末重选、等权持有）回放选股组合。
- 绩效展示：绘制组合累计收益率与沪深300指数基准的对比折线图，计算并展示年化收益率、最大回撤、区间胜率。
- 局限性标注：在回测面板显式标注三项局限说明：财务数据按实际披露时点取值避免未来函数、未扣除交易佣金与滑点、历史样本存在幸存者偏差。

#### 3.2.9 策略管理与每日监控
- 策略保存：支持将当前的一组筛选条件保存为自定义命名策略。
- 每日监控：支持将策略转为监控任务，每日以最新数据重跑策略，生成新增入选与退出标的的变动提示。

## 4. 业务规则与核心逻辑

### 4.1 AI 解析与确定性筛选边界规则
- AI 解析层仅负责自然语言意图理解、关键词抽取、口径澄清与逻辑冲突识别，严禁直接生成或推荐股票列表。
- 确定性筛选引擎完全独立于 AI，基于用户当前启用的结构化条件，对数据集进行布尔规则判定，相同输入必须产出完全一致且可复现的筛选结果。

### 4.2 冲突与歧义处理规则
- 硬冲突规则：当同一指标出现数学逻辑互斥（如要求 PE < 20 且 PE > 50），系统判定为硬冲突，提示错误并阻止执行筛选。
- 张力组合规则：当指标组合在业务常理上难以同时满足（如高成长与高股息并存），系统输出警示提示，但保留执行权限。
- 歧义澄清规则：对于未明确口径的模糊描述（如「估值合理」），系统提供「PE-TTM 历史分位 < 30%」、「PE-TTM 低于行业中位数」、「PB 历史分位 < 40%」等具体选项供用户选择。

### 4.3 标签与数据缺失判定规则
- 条件判断实行三态机制：当股票指标满足条件时标记为「通过」；不满足时标记为「不通过」；当该股票对应字段数值为空或无法获取时标记为「数据缺失」。
- 存在「数据缺失」项的股票，默认不归入最终通过名单，并在核对单中显式展示缺失提示，禁止隐式赋默认值。

### 4.4 数据来源与标注规则
- 数据层采用抽象接口设计，默认接入内置的 60-100 只 A 股样例数据集，并预留金融数据 API 接口切换能力。
- 每个指标数值均需绑定具体统计时点（如：财务数据截至 2026 年中报披露口径、行情数据截至 2026-09-25 收盘），界面展示结论需区分「客观事实」与「模型推断」。

## 5. 异常与边界情况

| 序号 | 异常/边界场景 | 系统处理逻辑 |
| :--- | :--- | :--- |
| 1 | 用户输入无选股语义的文本 | 提示无法识别有效选股意图，并引导点击预设示例短语 |
| 2 | 输入条件组合过严导致无股票通过筛选 | 候选列表显示为空，明确提示 0 只股票通过，并展示主要阻断条件 Top 排行 |
| 3 | 输入条件过宽导致全市场全量通过 | 正常展示结果，并在通过率统计条高亮提示筛选区分度较低 |
| 4 | 指标数据存在部分缺失 | 在核对单中标记为「数据缺失」，显式展示缺失字段，不作为符合条件处理 |
| 5 | What-if 调节超出指标合理定义域 | 限制调节滑块在指标合理取值区间内，阻止非法数值计算 |
| 6 | 历史回测区间内部分股票尚未上市 | 仅在各期调仓日对当时已上市且有数据的股票进行筛选计算，未上市期间不纳入组合 |

## 6. 验收标准

1. 用户在输入框输入选股文本或点击示例短语，点击解析后，系统在当前页面生成对应的结构化条件卡片，并展示解析步骤说明。
2. 面对「估值合理」等模糊输入时，系统弹出备选口径供用户确认；输入矛盾条件时系统提示硬冲突并阻止执行。
3. 用户修改任一条件卡片的阈值、切换启停状态或增删条件后，筛选结果列表及通过率统计实时更新且数据唯一可复现。
4. 点击候选或被排除股票，明细抽屉能够准确展示逐条件核对单，包含实际值、阈值、三态标签及数据时点口径。
5. 在 What-if 面板中调整选定条件的阈值比例（±10%/±20%），系统实时计算并展示边际进出股票名单与文字说明。
6. 用户可将候选股票加入对比观察池并查看横向对比表；可将当前条件保存为命名策略并开启每日监控设置。
7. 点击历史回测能够展示组合与沪深300基准的走势图及年化收益、最大回撤指标，且界面展示三项回测局限性说明与合规免责声明。

## 7. 本期不实现功能

1. 实盘交易与自动下单接口对接。
2. 个股买卖点精准择时预测与收益率保证算法。
3. 多因子加权模型自定义编码与复杂量化脚本编写引擎。
4. 用户间策略社区互动与策略跟投功能。
