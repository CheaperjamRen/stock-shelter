# 研选 · 自然语言智能选股与策略解释器

> 黑客松课题《自然语言智能选股与策略解释器》原型实现 · 面向 A 股投资研究场景的**研究辅助工具**（不构成任何投资建议）

把自然语言选股意图转化为**可检查、可修改、可执行的筛选条件**，由确定性引擎产出候选股票，并逐项解释入选 / 被排除原因、条件变化影响（What-if）与历史回测表现。AI 只负责"听懂意图并澄清歧义"，筛选本身是纯规则引擎——同一输入结果唯一、可复现、可核验。

**线上演示**：https://app-eq639ktulblt.miaoda.online

## 核心能力

### 1. 自然语言意图解析（规则式 NLU）
- 自然语言 → 结构化条件卡片，每张卡片携带**口径四要素**：定义 / 统计时点 / 数据来源 / 单位
- 歧义词（如「估值合理」）弹出**可选口径确认**，不擅自替用户决定
- **硬冲突阻断**（如同时要求「高股息」与「高成长」等互斥组）与**张力组合警示**
- **语义重复条件自动合并**：同一指标、同向比较、阈值一致时合并为一条并明示合并理由（详见「设计亮点」）

### 2. 确定性筛选引擎
- 纯规则求值：同一输入结果唯一可复现
- **三态判定**：通过 / 不通过 / 数据缺失——缺失显式提示、绝不静默赋默认值
- **逐条件核对单**：实际值 vs 阈值 + 三态标签 + 数据时点与来源（抽屉内查看，含被排除股票）
- 结果区支持因子排序、分页、**行业排除 / 恢复**、CSV 导出（UTF-8 BOM，Excel 打开中文不乱码）

### 3. 解释与推演（研究工作流）
- **What-if 敏感性**：任一条件阈值 ±10% / ±20%，展示放宽纳入 / 收紧剔除的边际名单
- **对比观察池**：多指标横向对比，池内最优 / 最差高亮
- **简化历史回测**：季度末调仓、等权持有；累计收益 vs 沪深300 演示基准；显式标注三项局限（财务按披露时点取值 / 未计交易成本 / 幸存者偏差）
- **策略与监控**：条件集保存为命名策略；一键开启每日监控（以上一交易日快照模拟每日重跑 diff）

### 4. 双数据源 · 真实 API 已接通
- **演示数据快照**（默认）：内置 A 股确定性快照，页面顶部显式标注「演示数据快照」，绝不伪装成实时数据
- **扶摇金融数据 API**（真实）：真实接入可用，见下文「接入真实数据」

## 设计亮点（贴合真实投研工作流，非噱头）

1. **条件语义去重合并**：实测中发现「超跌的优质白马，ROE 高于 15%」会同时命中数字条件抽取（ROE > 15）与关键词模板（白马 → ROE ≥ 15），生成两条同指标近阈值条件，导致排除原因 Top 出现近似重复项。修复：解析器按「同指标 + 同向比较 + 阈值一致（容差 1e-6）」合并为一条条件，并在解析过程步骤中**明示合并理由**，保留更显式的用户输入；不同阈值则保持并存，不做蕴含化简（避免 AI 替用户做主）。配套单测覆盖合并与并存两种场景。
2. **确定性优先，AI 只做翻译**：解析层负责理解与澄清，筛选由确定性引擎执行；页面明确写出这一边界，防止"AI 幻觉筛选结果"。
3. **事实与推断分开标注**：字段数值为「客观事实」，筛选归属 / What-if / 回测结论为「模型推断」。
4. **数据缺失不掩盖**：缺失值显式提示（三态中的缺数据态），不静默赋默认值后假装正常结论；真实 API 失败时红色 Alert + 重试，不静默降级。
5. **投研结果可带走**：CSV 导出让结果落到 Excel 做二次加工 / 留档。

## 技术栈

React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui + recharts · Vitest 单测（44 项全绿）。

```
src/
├── data/            # 数据层
│   ├── metrics.ts       # 指标目录（口径四要素，全站唯一口径来源）
│   ├── provider.ts      # Provider 抽象：demo | fuyao（自动探测 localStorage 中的 Key）
│   ├── fuyaoApi.ts      # 扶摇 API 客户端（direct 直连 / proxy 本地代理双模式，分块并发 + 缓存 + 限流）
│   ├── fuyaoMapper.ts   # 扶摇字段 → 内部 Stock 结构映射（缺失原因显式标注）
│   ├── stocks.ts        # 71 只 A 股演示快照（确定性生成，含缺失值注入）
│   ├── history.ts       # 回测历史（季度快照，财务滞后一期防未来函数）
│   ├── derive.ts / types.ts / rng.ts
├── engine/          # 引擎层（纯函数，独立于 UI 与 AI）
│   ├── screener.ts      # 确定性筛选引擎 + 三态判定
│   ├── parser.ts        # 意图解析（关键词 / 数字条件 / 歧义确认 / 语义去重合并）
│   ├── conflict.ts      # 硬冲突 / 张力组合检测
│   ├── whatif.ts / backtest.ts
├── state/           # ScreenerContext（全局状态）
└── components/screener/  # UI 面板（意图 / 条件 / 结果 / What-if / 观察池 / 回测 / 策略）
```

## 接入真实数据（扶摇金融数据 API）

真实 API 已接通，无需改代码。Key 的持有遵循安全原则：**密钥绝不写入代码仓或文档**，只经过环境变量 / 浏览器 localStorage 传递。

### 线上部署（直连模式）
1. 打开线上应用，在「数据源」状态条点击并填入扶摇 API Key（或通过浏览器控制台执行 `localStorage.setItem('fuyao_api_key', '您的Key')` 后刷新）
2. Key 仅保存在本机浏览器 localStorage；填 Key 后顶部徽标切换为「真实数据 API」
3. 前端直连 `https://fuyao.aicubes.cn/api`（CORS 已放行），请求头带 `X-api-key`
4. 不填 Key 时自动使用内置演示数据快照，并显式标注，绝不伪装成实时数据

### 本地开发（代理模式，Key 不进 bundle）
```bash
# .env（已被 .gitignore 排除，不进仓库）
FUYAO_API_KEY=您的Key

npm install
FUYAO_API_KEY=您的Key npm run dev   # 前端走 /fuyao/api 代理，Key 仅存于本地进程环境变量
```

### 降级与合规
- 接口调用失败：红色错误提示 + 重试按钮，**不会**静默降级为演示数据后伪装成实时结论
- 数据缺失 / 过期：显式标注缺失原因与时点
- 不构成投资建议，不输出确定性涨跌预测、收益承诺或买卖建议
